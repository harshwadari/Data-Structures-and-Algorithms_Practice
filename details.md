## 21. Core Algorithmic Patterns Cheat Sheet & Decision Matrix

When faced with a new problem in interviews, use this decision framework to instantly identify the optimal approach:

```
┌───────────────────────────────────────────────┬─────────────────────────────────────────────────────────────┐
│ If the problem involves...                    │ Immediately think about...                                  │
├───────────────────────────────────────────────┼─────────────────────────────────────────────────────────────┤
│ Sorted array, find pair / triplet             │ Two Pointers (Inward Scan: left += 1 or right -= 1)         │
│ Subarray / Substring with condition           │ Sliding Window (Expand right, shrink left when invalid)     │
│ Next Greater / Smaller / Histogram rectangle  │ Monotonic Stack (Store indices of increasing/decreasing)    │
│ Search space has monotonic boolean property   │ Binary Search on Answers (low=min_val, high=max_val)        │
│ Find all permutations, subsets, combinations  │ Recursion / Backtracking (Pick / Not Pick or Loop Choices)  │
│ Connected components, shortest path in grid   │ BFS (Level-order / Multi-source) or DFS                     │
│ Shortest path with non-negative edge weights  │ Dijkstra's Algorithm (Min-Heap / Priority Queue)            │
│ Shortest path with negative edge weights      │ Bellman-Ford Algorithm (Relax all edges V-1 times)          │
│ All-pairs shortest path                       │ Floyd-Warshall Algorithm (3 nested loops matrix DP)         │
│ Topological ordering, prerequisite courses    │ Kahn's Algorithm (BFS Indegree array) or DFS Stack          │
│ Minimum Spanning Tree / Connected components  │ Disjoint Set Union (DSU) + Kruskal's / Prim's Algorithm     │
│ Count ways, min/max path sum, overlapping sub │ Dynamic Programming (State -> Transition -> Base Case)      │
│ In-place linked list cycle / midpoint         │ Floyd's Tortoise & Hare (Fast = 2x, Slow = 1x)              │
│ Array elements in range [1, N]                │ Cyclic Sort (Place arr[i] at index arr[i] - 1)              │
│ Strict majority element (> N/2)               │ Boyer-Moore Voting Algorithm (Candidate & Count)            │
└───────────────────────────────────────────────┴─────────────────────────────────────────────────────────────┘
```
